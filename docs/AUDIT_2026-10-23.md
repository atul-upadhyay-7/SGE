## Fixed in this branch

### Security / correctness (backend)

1. **Starlette vulnerabilities (was: 12 known CVEs).** `fastapi`
   0.116.1 → 0.161.1 and an explicit `starlette==1.9.0` pin (FastAPI
   declares only a floor for Starlette). `pip-audit` is now clean.
   The upgrade changed FastAPI's route tree (`_IncludedRouter`
   wrappers), which made the route-inventory tests enumerate *zero*
   routes — the read-access test failed, but the **write-guard
   inventory test passed vacuously**, silently disabling the check
   that every write route has an auth guard. Both inventories now
   recurse into included routers, and the write test asserts its
   inventory is non-empty.
2. **HTTP ingestion lied about failed writes.** `_flush()` swallowed
   DB failures and `ingest_now()` still returned `201 "stored"` for a
   sample that was rolled back. The flush outcome now carries
   `failed`, the HTTP path maps it to `503 storage_failed` so devices
   retry, and live-stream events are published only for rows actually
   inserted (duplicates no longer emit phantom `telemetry` events).
3. **One far-future sample poisoned a device forever.**
   `last_seen_at` is monotonic and staleness reads `measured_at`, so a
   sample dated e.g. 9999 disabled the `device_stale` rule permanently.
   `measured_at` more than `telemetry_max_future_skew_s` (default 7 d)
   in the future is now rejected as out of range; past backfill is
   still accepted.
4. **Unvalidated settings.** Queue sizes / intervals / pool sizes had
   no lower bounds; `0` silently meant "unbounded queue" or a
   busy-looping monitor. They now carry `Field(gt=0)`-style
   constraints and fail at startup. Production startup also refuses
   the CORS `*` + credentials combination.
5. **Registration accepted unusable devices.** `device_id` now must
   be MQTT-topic-safe (`^[A-Za-z0-9][A-Za-z0-9_-]*$`); `chemistry`
   must name a known anomaly profile (`li_ion|lifepo4|nimh|lead_acid`)
   instead of silently falling back to li_ion thresholds.
6. **Unbounded payload.** `cell_voltages` is capped at 1024 entries
   at the schema boundary (devices declare ≤ 64 cells).
7. **Monitor health hid failures.** Per-device tick failures were
   logged and then `last_error` was cleared, so `/health/monitor`
   reported OK during a total outage. The tick now counts failures
   and health returns 503 with `last_tick_failures`.
8. **Model version hashing on the event loop.** `model_version()`
   re-read and SHA-256-hashed the 1.1 MB artifact on every cycle
   aggregation. It is cached on `(mtime, size)`.

### ML pipeline

9. **Pack evaluation fabricated predictions.** `src/pack/evaluate.py`
   fell back to `predicted_soh = soh` (the target) when no prediction
   files existed. It now raises, like `main()` already did for too few
   cells.
10. **Served RUL curves were smoothed twice.** `TrajectoryRul.save()`
    persists the smoothed curves and `load()` smoothed them again, so
    the bridge served different references than evaluation scored.
    `load()` now constructs with `smooth=False`; a save→load
    round-trip test pins this.
11. **Test fixture did not mirror the model contract.**
    `tests/conftest.py` `ACTIVE_FEATURES` carried `"cycle"` (which
    `features.py` deliberately excludes) and none of the 16 causal
    features the shipped model consumes. The list now matches
    `features.FEATURES` minus `ambient_temperature`, `cycle_row`
    carries the causal fields, and a test pins the list to the source
    of truth.
12. **Alert exporter emitted invalid Prometheus values** for ±inf
    (`repr(inf) == "inf"` poisons a scrape); now `math.isfinite`.
    Its default bind is loopback, like the Grafana API (compose sets
    `0.0.0.0` explicitly inside its network).

### Frontend

13. **No route-level code splitting.** All 8 pages were in the entry
    chunk (301 KB / 92 KB gzip). Pages are `React.lazy` now; the entry
    chunk is 223 KB / 73 KB gzip and each page loads on demand.
14. **`apiFetch` timeout stopped at the headers.** A backend that
    stalled mid-body hung forever. The timer now covers `response.text()`,
    body errors normalise to `NetworkError`, and the external abort
    listener is removed.
15. **`useAsync` showed the previous entity's data.** Navigating
    anomaly A → B rendered A — with A's resolution actions enabled —
    until B loaded. Data is cleared on dependency change.
16. **Overview counted `false_positive` as active**, inflating the
    anomaly KPI and the critical banner. Terminal states are now both
    excluded.
17. **CSV formula injection.** Exported string cells beginning with
    `=`, `+`, `-`, `@` are quote-prefixed (genuine numbers untouched);
    blob-URL revocation is deferred so it cannot cancel downloads.
18. **SSE reconnect hammering.** Fixed 3 s retries forever on a
    permanent failure; now exponential backoff to a 60 s cap, and the
    frame buffer is capped at 1 MiB.
19. **Small defects:** pack-level anomalies (`affected_cell = 0`)
    indexed `cell_voltages[-1]`; the Devices form kept the admin key
    in state after a successful registration; every page had two
    `<h1>` elements (top-bar brand is no longer a heading).

### Tests / CI / DevOps

20. **Dataset-dependent root tests failed instead of skipping** on a
    clean clone (4 failures), contradicting the suite's own pattern;
    `resolve_raw_dir()` raises before the existing existence guards
    could run. They now skip with a pointer to
    `scripts/download_dataset.sh`.
21. **CI never ran the root suite and no linter existed.** Added to
    `verify.yml`: a `lint` job (Ruff, config in the new `ruff.toml`,
    core rules `E4,E7,E9,F,I` — the tree is clean under it, including
    mechanical import sorting) and a `root-tests` job; per-job
    `timeout-minutes` everywhere. One autofix trap was caught by the
    backend suite: Ruff removed intentional re-exports from
    `app/ml/estimator.py` (restored with an explicit `noqa: F401`).
22. **`.env` could be baked into Docker images.** `.dockerignore`
    now excludes `.env*`, `*.pem`, `*.key`, `logs/`,
    `frontend/node_modules|dist` (`.env.example` stays allowed).
23. **Postgres and Grafana were published on all interfaces** with
    documented default credentials; both are loopback-bound now, like
    every other service. (MQTT stays LAN-facing — the ESP32 needs it.)
24. **Webhook receiver had an unbounded body read** (unauthenticated
    disk-fill inside the compose network); capped at 1 MiB → 413.
25. **No dependency-update automation.** `.github/dependabot.yml`
    covers pip (root + backend), npm, Docker and GitHub Actions
    weekly — the Starlette situation is what happens without it.
26. **Backend image had no healthcheck**; added one against the open
    `/api/v1/health` liveness route.

## Not fixed here — prioritised plan

These need a design decision, a migration, the NASA dataset, or
hardware/compose verification that a code-only branch cannot honestly
provide. In priority order:

### P0 — before any non-local deployment
- **Compose default credentials** (`bms`/`bms`, Grafana `admin`/
  `admin`) still exist as `${VAR:-default}` fallbacks. Loopback
  binding (done) limits exposure locally; for any shared host, switch
  to `${VAR:?must be set}` or Docker secrets and add a
  `docker-compose.prod.yml` that also sets
  `BMS_ENVIRONMENT=production` with the three API keys (compose today
  sets neither, bypassing the backend's production guard).
- **Anonymous MQTT on the LAN** (`allow_anonymous true`, port 1883 on
  all interfaces) is documented as demo-only, but anyone on the LAN
  can publish forged telemetry. Add a password file + ACL (and TLS on
  8883) before connecting real hardware.
- **`anomaly.py` reads the *uncleaned* dataset**
  (`nasa_ml_dataset.csv`), contradicting the "every downstream stage
  reads the cleaned file" contract — it scores audit-excluded cells
  with a different SOH definition. Pointing it at
  `nasa_ml_dataset_clean.csv` changes published numbers, so it needs
  a regeneration run with the dataset present and a `CHANGES.md`
  entry, not a silent constant change.

### P1 — correctness / robustness
- **Concurrent aggregation can duplicate predictions**
  (`cycle_repository` delete+insert, no lock, no unique constraint):
  take a per-device advisory lock in `aggregate_device()` and have
  the manual endpoint update `last_aggregated_at` too.
- **Anomaly/alert transitions are check-then-act** with unconditional
  `set_status()` writes (a concurrent resolve can be resurrected),
  and the anomaly partial unique index covers only `status='open'`
  while the app treats three states as open. Conditional updates +
  `ON CONFLICT` + a widened index (migration).
- **Report-queue admission race**: the pending bound is checked
  before an `await`, so concurrent requests can all pass; reserve the
  slot synchronously (the cross-process bound is already documented
  in `docs/TODO.md`).
- **Device cache is load-once**: if the startup load fails, every
  pre-existing device is rejected as `unknown_device` until restart.
  Add retry/backoff and a DB lookup on cache miss.
- **Synchronous inference on the event loop**: `predict_soh` runs
  inline in `aggregate_device()`; move it to `run_in_threadpool`
  (the PDF path already does this).
- **Report N+1**: `_actions()` issues up to ~10k sequential queries;
  `list_reports()` loads full snapshot JSONB to build summaries;
  the gap summary window-scans all telemetry for unbounded reports.
  Batch the actions query, use `load_only`, bound the gap window.
- **Ingestion writer rarely batches** (drains with `get_nowait()`
  only): collect until batch size or the flush deadline.
- **Telemetry rejections are unbounded**: every bad message stores
  its full raw payload with no cap/retention — truncate `raw_payload`
  (16 KB) and add a retention policy; add a body-size limit
  middleware for the ingest routes.

### P2 — ML methodology (document or fix deliberately)
- `anomaly.py` thresholds (residual bounds, knee σ) are computed over
  each cell's *whole life* — a flag at cycle *t* depends on cycles
  > *t*. Either relabel as offline screening or switch to
  training-cell / trailing-window statistics.
- `run_experiments.py` cell-relative fallback fills a missing opening
  baseline with the cell's whole-lifetime median (future leakage,
  edge case); mirror `features.window_model_row` (opening median →
  1.0) and add a zero-baseline test.
- Constant-feature dropping happens on the full frame before LOCO in
  `train_soh.py` / `anomaly.py` / `run_experiments.py`, against the
  protocol in `features.py`; move it inside folds or pre-register
  the dropped set.
- Grafana stat tiles ignore the dashboard's cell/group selection and
  "latest SOH" orders by `cycle DESC` across cells; apply
  `scope_filter()` and a deterministic order.
- `dashboard/load_to_sqlite.py` hardcodes the four G1 cells for the
  merged RUL view, silently omitting the other kept cells' RUL
  predictions; derive members from the loaded tables.
- `grafana_api.py`: CORS is unrestricted and `/query` ignores the
  Grafana time range with no row limit (mitigated by loopback
  defaults). Restrict origins, honour `range`, add `LIMIT`. Several
  `except: pass` blocks in `grafana_api.py` / `alert_exporter.py`
  should log and distinguish "no DB yet" from "DB broken".
- Root-anchored paths: most ML entry points use CWD-relative paths
  and only work from the repo root; adopt the
  `Path(__file__).resolve().parent.parent` pattern already used by
  `window_partial.py` / `pack/evaluate.py`.

### P2 — frontend
- Runtime validation at the HTTP boundary is absent
  (`return parsed as T`); validate at least predictions, report and
  stream-event payloads, and make `formatPercent` finite-safe.
- Anomaly Center sort/export act on the current page (25 rows) while
  presenting as global; move sorting server-side and export the full
  filtered set (or relabel honestly). Filter inputs fire ~5 requests
  per keystroke — add draft state + debounce; the current "Apply"
  button is a no-op.
- Polling continues in background tabs; the immutable report detail
  re-fetches every 30 s; the Grafana iframe is eager despite the
  README claiming lazy loading. Pause on `visibilitychange`, stop
  detail polling once ready, add `loading="lazy"`.
- Dead API surface: `services/alerts.ts` (whole module),
  `getRul`, `getAnomalyRecurrence`, `updateDeviceCredential`,
  `PlaceholderPage` have no callers — delete or mark as planned.
- Clickable `<tr>` rows nest links/buttons (keydown bubbling, focus
  outline removed by `.table__row--clickable:focus-visible`); charts
  claim a data-table alternative that doesn't exist and have
  duplicate React keys for multi-day hourly buckets.
- Battery Health conflates any error with "no prediction yet" (only
  a literal `"Not found"` message string is distinguished); branch on
  the typed `ApiError.status === 404` and offer retry.
- Mid-session 401 unmounts the whole app (AuthGate), discarding
  in-progress form/workflow state; render the key prompt as an
  overlay instead.

### P3 — DevOps hardening
- Containers run as root with writable shared mounts and no
  `cap_drop`/`read_only`/resource limits: add a non-root `appuser`
  to both Dockerfiles, mount `models` (and `data` for read-only
  services) `:ro`, and verify with the compose smoke job in CI
  before merging (not verifiable in this audit environment).
- Grafana cookie posture: compose env defaults (`lax`/`false`)
  override the hardened `grafana.ini` (`none`/`true`); make the
  HTTPS profile explicit.
- Supply chain: floating image tags (`eclipse-mosquitto:2`,
  `python:3.12-slim`), unversioned Grafana plugin installed at boot,
  mutable action tags; pin by digest/SHA and consider adding
  `pip-audit`/Trivy/gitleaks jobs (Dependabot now covers freshness).
- `scripts/grafana_alerts.py` defaults to `admin`/`admin` — read
  from `GRAFANA_USER`/`GRAFANA_PASSWORD` and fail when unset for
  non-local URLs.
- Firmware (documented untested on hardware): plaintext
  unauthenticated MQTT and unbounded Wi-Fi/NTP connect loops — add
  broker auth/TLS support and connect timeouts when hardware work
  starts.
- Duplicate Grafana provisioning trees (`dashboard/provisioning/`
  vs `docker/grafana/provisioning/`) have already diverged in file
  sets; consolidate to one source of truth.

## Strengths worth keeping (verified)

- Backend credential handling (SHA-256 digests, `hmac.compare_digest`,
  secrets stripped before persistence), route-inventory auth tests,
  keyset pagination, atomic report claiming with heartbeat recovery,
  PDF escaping + threadpool offload, single linear Alembic chain.
- ML leakage discipline: single-sourced `LEAKY_FEATURES`, nested LOCO
  tuning, causal past-only features, byte-identical reproducibility
  tooling, honest README/MODEL_CARD limits.
- Frontend: strict TS (`noUnusedLocals` etc.), no
  `dangerouslySetInnerHTML`/`eval`, keys only in `sessionStorage`,
  viewer key in headers (never URLs), bundle-secret e2e scan,
  systematic loading/error/empty states.
- No committed secrets anywhere; `.gitignore` coverage is thorough.

## Model / ML (`9a70287`)

- `src/anomaly.py` now reads the **cleaned** dataset
  (`nasa_ml_dataset_clean.csv`); it previously ran on the uncleaned
  file. **Reproduce:** `grep -rn "nasa_ml_dataset_clean" src/anomaly.py`; inspect `tests/test_anomaly.py` for prefix-invariance. Thresholds are **causal**: residuals and the knee detector
  judge each cycle only against earlier cycles of the same cell
  (`causal_robust_bounds`, 10-cycle minimum history), so results no
  longer depend on future data. Prefix-invariance tests prove it.
- The constant-feature protocol is pre-registered by name
  (`PREREGISTERED_CONSTANT_FEATURES` in `src/features.py`) instead

  the full-frame check itself was a (mild) form of leakage.
- `run_experiments.cell_relative_features` no longer falls back to
  the whole-lifetime median when the opening baseline is missing;
  it falls back to 1.0, mirroring the serving path
  (`features.window_model_row`).

  another working directory no longer reads/writes the wrong tree.
- `src/pack/evaluate.py` refuses to score when predictions are
  missing (left-join NaN guard) instead of silently dropping rows.
- Dead code removed (`evaluation.logo_evaluate`/`split_by_group`,
  `train_rul.select_features` plumbing).
- New `tests/test_anomaly.py` (7 tests) covers the above.
  **Reproduce:** `python -m pytest tests/test_anomaly.py -v`
- **Not done, deliberately:** the anomaly artifacts under
  `data/processed/` were not regenerated — run `run_pipeline.py`
  once so the stored artifacts match the causal thresholds.
  **Reproduce:** `python run_pipeline.py` *(or `python run_pipeline.py --skip-train` per pipeline flags)*
- Verified: root suite **320 passed, 20 skipped**; Ruff clean.
  **Reproduce:** `python -m pytest -q` (root) and `ruff check .`

## Backend (`ca786d0`)

- Per-device cycle aggregation is serialised with a Postgres
  advisory transaction lock; the manual aggregate endpoint now
  stamps `last_aggregated_at` like the background path. SoH
  inference runs in the threadpool instead of blocking the loop.
- Anomaly lifecycle transitions are conditional single UPDATEs
  end to end (`set_status`, `resolve_event`, alert `ack_alert`):
  the loser of a concurrent resolve/acknowledge gets a 409
  instead of resurrecting a closed event. `open_or_extend` falls
  back through a savepoint on the unique-index race, and migration
  `a9c1e2f3b4d5` widens the open-episode partial unique index to
  `open/acknowledged/investigating`, closing the duplicate-episode
  hole for acknowledged events.
- Server-side anomaly list sorting (severity ranked in SQL,
  stable id tiebreak) — pairs with the frontend change below.
- Report queue admission reserves its slot **before** any await,
  so concurrent requests can no longer overshoot capacity; report
  building uses one batched corrective-action query instead of an
  N+1 over up to 10k events; the list endpoint defers the payload
  column; the gap scan window is bounded to 90 days.
- Ingestion: a device missed by the startup cache load recovers
  via one DB lookup (misses negative-cached 30 s); the writer loop
  flushes on its interval deadline, not only on full batches;
  oversized payload extras are rejected; stored rejection payloads
  are truncated with a preview marker.
- Telemetry ingest bodies are capped at 1 MiB (new setting) with a
  413; `/health` no longer leaks driver error text; frozen
  module-level settings snapshots removed.
- Verified: **267 passed** against PostgreSQL 16 (262 + 5 new
  second-pass tests); `alembic upgrade head` and `alembic check`
  clean; Ruff clean.
  **Reproduce:** `cd backend && BMS_REQUIRE_DB=true BMS_MQTT_ENABLED=false BMS_MONITOR_ENABLED=false BMS_DATABASE_URL=postgresql+asyncpg://bms:bms@127.0.0.1:5433/bms python -m alembic upgrade head && python -m alembic check && python -m pytest -ra`

## Frontend (`7ba3fe8`)

- API responses are shape-validated (`services/validate.ts`): a
  2xx with an unexpected body surfaces as an error instead of
  crashing a render later; live stream frames are checked before
  use. Any 401 raises the auth prompt; report downloads get a
  60 s timeout and safe RFC 5987 filename handling.
- Anomaly Center: sorting is server-side across the whole result
  set (was: current page only); filters are draft/applied with a
  400 ms debounce (was: one aborted request per keystroke); CSV
  export walks the full filtered set, bounded at 1,000 rows (was:
  the visible page only).
- Battery Health branches on the typed `ApiError.status` — the
  hooks now expose `errorStatus` — so 404 means "no prediction
  yet" and anything else is an error card with retry (was: every
  error rendered as "no prediction yet", keyed off the message
  string `"Not found"`).
- `AuthGate` is an overlay and the app stays mounted behind it, so
  a mid-session key rotation no longer discards form state; hooks
  reload on the new `bms:auth-resolved` event. `DeviceSelector`
  clears a selection whose device was deleted. Reports form device
  follows the shared selection until edited; report detail polling
  stops at terminal status; Devices/System Health row summaries
  poll with their lists; polling pauses in hidden tabs.
- Charts now ship the accessible data table their header comment
  always claimed, with duplicate React keys fixed; Grafana iframe
  lazy-loads; clickable rows ignore keys from nested controls and
  keep a visible focus outline.
- Dead code removed: `services/alerts.ts`, `PlaceholderPage`,
  `getRul`, `getAnomalyRecurrence`, `updateDeviceCredential`,
  `RulInfo`/`Alert` types.
- Verified: vitest **12 passed**, `tsc` clean, production build
  clean.
  **Reproduce:** `cd frontend && npm test && npm run typecheck && npm run build`
